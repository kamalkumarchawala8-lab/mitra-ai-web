# Mitra AI – Har Sawaal Ka Dost

Ye Vercel pe deploy karne ke liye ready project hai.

## GitHub pe upload karne ke steps
1. GitHub pe naya repository banao (jaise `mitra-ai-web`)
2. Is poore folder ke andar ki saari files/folders (`src`, `index.html`, `package.json`, etc.) upload karo — **poora `mitra-ai-web` folder ka andar wala content**, na ki khud folder ko zip karke
3. "Commit changes" karo

## Vercel pe deploy karna
1. vercel.com pe GitHub se login karo
2. "Add New Project" → apna `mitra-ai-web` repo select karo
3. "Deploy" dabao — Vercel khud framework (Vite) detect kar lega
4. 1-2 minute me live link mil jaayega (jaise `mitra-ai-web.vercel.app`)
